## 新增资料

- 接口图纸放在 `interfaces/<接口名称>/`，配套的接口模型与图纸放在一起。
- 打印件放在 `printed_parts/<部件名称>/`。有左右手或安装对象之分时，再按型号建子目录。
- 同一版本的 STEP、预览图和可选的 STL 或 3MF 放在同一目录。保留原始图号和文件名，并在上表添加链接。
